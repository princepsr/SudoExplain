---
title: Security bugs explained from real failures
description: Broken access control, injection, leaked secrets and token mistakes, explained with how they happen, how to spot them and how to fix them.
---

Most security bugs in everyday applications are not clever attacks. They are ordinary mistakes: a check that was forgotten, input that was trusted, or a secret that ended up in the wrong place.

The posts below start from a realistic mistake, show how it can be used against the application, and explain how to find it in your own code. Each one compares the fixes and explains how a fix can be bypassed.

These posts explain defence for developers building and reviewing their own systems.
